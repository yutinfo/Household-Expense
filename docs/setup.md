# เตรียมตัวก่อนติดตั้ง (Phase 0)

เอกสารนี้คือรายการตัดสินใจและของที่ต้องเตรียม **ก่อน** ลงมือทำตาม [deploy.md](deploy.md)

---

## สิ่งที่ต้องมี

| ของ | ทำไม | ค่าใช้จ่าย |
| --- | --- | --- |
| บัญชี Google ส่วนตัว | เจ้าของ Sheets + Apps Script + Drive | ฟรี |
| LINE Official Account (Messaging API) | บอทในกลุ่ม | ฟรี (ส่ง Push ได้ ~300 ข้อความ/เดือน) |
| บัญชี Cloudflare | Worker ตรวจลายเซ็น | ฟรี |
| Node.js บนเครื่อง | deploy Worker | ฟรี |
| Google AI Studio API key | AI (ทำทีหลังได้) | ตามการใช้งาน |

> แนะนำ**บัญชี Google ส่วนตัว** ไม่ใช่บัญชีที่ทำงานให้ — ถ้าออกจากงานแล้วบัญชีถูกปิด ข้อมูลบัญชีครอบครัวจะหายไปด้วย

## แยกข้อมูลทดสอบกับข้อมูลจริง

สร้าง Google Sheets **2 ไฟล์** ตั้งแต่แรก:

| ไฟล์ | ใช้ตอน |
| --- | --- |
| `Household Expense (TEST)` | ติดตั้ง ทดลอง ลองคำสั่งแปลก ๆ ลองพัง |
| `Household Expense (PROD)` | ใช้จริงหลังทดสอบผ่าน |

สลับกันแค่เปลี่ยน Script Property `SPREADSHEET_ID` — ไม่ต้องแก้โค้ด

## ขอบเขตที่ตกลงกันไว้

- ใช้ในกลุ่ม LINE เดียว มีสมาชิก 2 คนกับบอท 1 ตัว
- Google Sheets เป็นฐานข้อมูลหลัก **ไม่มี**ฐานข้อมูลอื่นเก็บยอดเงินซ้ำ
- คนพิมพ์ = คนจ่าย โดยปริยาย แต่ระบุคนอื่นได้ (`เมียจ่าย`)
- รายจ่ายครอบครัวนับ**เต็มจำนวน** ไม่หารครึ่ง ไม่สร้างหนี้ระหว่างสามีภรรยา
- ใช้เงินบาท และวันบัญชีตามเวลา `Asia/Bangkok`
- รายการชัดเจน → บันทึกทันที / รายการกำกวม → พักไว้ถามก่อน
- โอนกันเองในครอบครัวไม่นับเป็นรายจ่าย เงินคืนหักจากหมวดที่เกี่ยวข้อง
- งบรายหมวดเริ่มที่ "ยังไม่ตั้งงบ" จนกว่าจะสั่งเอง — **AI ตั้งงบเองไม่ได้**
- รุ่นแรกใช้ข้อความ ส่วนรูปสลิป (Phase 8) เปิดทีหลังได้
- ทั้งสองคนแก้รายการของกันและกันได้ แต่ต้องยืนยันและมีประวัติเสมอ

| --- | --- |
| `food` | อาหาร |
| `home` | ของใช้และตกแต่งบ้าน |

| `travel` | เดินทาง |
| `bills` | บิลประจำ |

## ตั้งชื่อเล่นให้ถูกตั้งแต่แรก

ในแท็บ `Members` คอลัมน์ `aliases` คั่นด้วยจุลภาค เช่น:

| member_id | display_name | aliases |
| --- | --- | --- |
| `yut` | ยุทธ | `ยุทธ,ผม,สามี,พี่` |
| `wife` | ภรรยา | `เมีย,ภรรยา,แฟน,เธอ` |

ชื่อเล่นเหล่านี้ใช้เข้าใจประโยคอย่าง `ผ้าอ้อมลูก 499 เมียจ่าย` และ `โอนให้เมีย 3000` — ใส่คำที่ใช้จริงในบ้าน
