# คำสั่งทั้งหมด

พิมพ์ในกลุ่ม LINE ที่มีบอทอยู่ (คำสั่งใช้ได้เฉพาะสมาชิกที่ลงทะเบียนแล้ว)

---

## บันทึกรายจ่าย

| รูปแบบ | ตัวอย่าง | ผล |
| --- | --- | --- |
| `<รายการ> <ยอด>` | `ค่าส้มตำ 200` | รายจ่าย 1 รายการ |
| ติดกันไม่เว้นวรรค | `ค่าส้มตำ200` | เหมือนกัน |
| หลายรายการ | `กาแฟ 65 ข้าว 80` | 2 รายการ |
| ระบุวัน (คำ) | `เมื่อวานเติมน้ำมัน 300` | ลงวันเมื่อวาน |
| ระบุวัน (ตัวเลข) | `ค่าข้าว 120 5/9/2026` | ลงวันที่ระบุ |
| ระบุผู้จ่าย | `ผ้าอ้อมลูก 499 เมียจ่าย` | payer = ภรรยา |
| มีสตางค์ | `ค่าอาหาร 125.50` | 125.50 บาท |
| มีลูกน้ำ | `ค่าเช่า 12,000` | 12,000 บาท |
| เลขไทย | `ค่าข้าว ๒๐๐` | 200 บาท |
| คำบอกจำนวน | `ค่าโต๊ะห้าพัน` | 5,000 บาท |
| เงินคืน | `คืนเสื้อ ได้เงินคืน 200` | refund หักจากหมวดเดิม |
| โอนกันเอง | `โอนให้เมีย 3000` | transfer ไม่นับรายจ่าย |

**ไม่บันทึก:** ข้อความที่เป็นแผน (`ว่าจะซื้อ...`, `อยากได้...`) หรือคำถาม

## บันทึกรายรับ

| รูปแบบ | ตัวอย่าง | ผล |
| --- | --- | --- |
| `<คำบอกรายรับ> <ยอด>` | `เงินเดือน 30000` | รายรับ 30,000 |
| | `โบนัส 5000` | รายรับ 5,000 |
| | `ขายของได้ 800` | รายรับ 800 |

คำที่ระบบรู้จักว่าเป็นรายรับ: `เงินเดือน` `โบนัส` `รายรับ` `เงินเข้า` `ได้รับเงิน` `ขายของได้` `ค่าจ้าง` `ดอกเบี้ย`

- รายรับ **ไม่มีหมวด** และ **ไม่กินงบประมาณ** — ไม่ไปปนกับยอดรายจ่ายเลย
- `ได้เงินคืน 200` ยังเป็น **เงินคืน** (ลดยอดหมวดเดิม) ไม่ใช่รายรับ
- หนึ่งข้อความ = หนึ่งรายรับ ถ้าพิมพ์ `เงินเดือน 30000 โบนัส 5000` ระบบจะขอให้แยกพิมพ์
- เดือนที่มีรายรับ `เดือนนี้` จะเพิ่มบรรทัด **รายรับ** และ **คงเหลือ** ให้

## ดูยอด

| คำสั่ง | ผล |
| --- | --- |
| `วันนี้` | ยอดวันนี้ แยกหมวด |
| `เดือนนี้` | ยอดเดือนนี้ + สถานะงบ |
| `เดือนที่แล้ว` | ยอดเดือนก่อน |
| `เดือนนี้ค่าอาหารเท่าไหร่` | เฉพาะหมวดนั้น (ใช้ได้กับทุกหมวด) |
| `เดือนนี้ใครจ่ายเท่าไหร่` | แยกตามผู้จ่าย |
| `เทียบเดือนก่อน` | เทียบช่วงวันเท่ากัน |
| `รายการล่าสุด` | 5 รายการล่าสุดพร้อมรหัส |

## แก้ไข / ยกเลิก

| คำสั่ง | ผล |
| --- | --- |
| `ยกเลิก T7K2QA` | ถามยืนยันก่อนยกเลิก |
| `แก้ T7K2QA ยอด 250` | เปลี่ยนจำนวนเงิน |
| `แก้ T7K2QA หมวด อาหาร` | เปลี่ยนหมวด |

| `แก้ T7K2QA ผู้จ่าย เมีย` | เปลี่ยนผู้จ่าย |

| `แก้ T7K2QA` | เปิดเมนูปุ่ม |

ทุกการแก้แสดง **ก่อน/หลัง** และต้องกดยืนยัน

## ปุ่มที่พบ

| ปุ่ม | ความหมาย |
| --- | --- |
| ชื่อหมวดต่าง ๆ | เลือกหมวดให้รายการที่บอทไม่รู้ |
| แก้ไข / ยกเลิกรายการ | จัดการรายการที่เพิ่งบันทึก |
| ยืนยัน / ไม่แก้ | ยืนยันการเปลี่ยนแปลง |
| จำไว้ / ครั้งนี้ครั้งเดียว | สอนกฎหมวดถาวรหรือไม่ |
| ยืนยันบันทึก / แนบกับ T... / แก้ข้อมูล / ยกเลิก | จัดการรูปสลิป |

ปุ่มผูกกับคนกดและรายการนั้น — คนอื่นกดแทนไม่ได้ กดซ้ำก็ไม่เกิดผลซ้ำ และมีวันหมดอายุ

## ฟังก์ชันสำหรับเจ้าของระบบ (รันใน Apps Script เท่านั้น)

| ฟังก์ชัน | ใช้เมื่อ |
| --- | --- |
| `setupSpreadsheet()` | สร้าง/ซ่อมแท็บทั้งหมด (รันซ้ำได้) |

| `authCloseOnboarding()` | ปิดรับสมัคร |
| `configHealthCheck()` | ตรวจว่าตั้งค่าครบไหม (ไม่โชว์ secret) |
| `maintenanceStatusReport()` | รายงานสุขภาพระบบทั้งหมด |
| `recoveryRun()` | เก็บงานค้างเดี๋ยวนี้ |
| `recoveryAudit()` | ตรวจความสอดคล้องของข้อมูล |

| `maintenanceEnablePush()` / `maintenanceDisablePush()` | เปิด/ปิด Push |
| `backupRun()` | สำรองเดี๋ยวนี้ |
| `backupFingerprint()` | ลายนิ้วมือข้อมูล ใช้เทียบตอนกู้ |
| `dashboardRefresh('2026-09')` | อัปเดต Dashboard |
| `schedulerInstall()` | ติดตั้ง trigger ทั้งหมด |
| `schedulerRemoveAll()` | ถอด trigger ทั้งหมด |
