- [x] แยกไฟล์ TEST/PROD ได้ด้วยการเปลี่ยน config ตัวเดียว

- [x] ลงทะเบียนสมาชิกด้วยรหัสใช้ครั้งเดียว หมดอายุได้ และปิดรับสมัครได้
- [ ] **ต้องทำจริง:** สร้างบัญชี Google/LINE/Cloudflare และ deploy Web App

## ข้อจำกัดที่ยอมรับในรุ่นนี้

1. **Google Sheets ไม่ใช่ transactional database** — ระบบชดเชยด้วย event journal, idempotency key และ recovery แต่ไม่ใช่ ACID จริง
2. **การแก้ชีตด้วยมือข้าม ScriptLock และ AuditLog** — ต้องใช้วินัย แก้ผ่านบอทเป็นหลัก
3. **เวลาของ trigger คลาดเคลื่อนได้** — ระบบจึงพูดว่า "ช่วงประมาณ" ไม่รับประกันตรงนาที
4. **AI อ่านผิดได้** — มี validator และให้ผู้ใช้ยืนยัน/แก้ได้เสมอ
5. **การแจ้งเตือนคุมได้เฉพาะเงินที่บันทึกไว้** — ระบบไม่รู้ยอดที่ไม่ได้จด และห้ามการใช้เงินจริงไม่ได้
6. **สำรองในบัญชี Google เดียวกัน** ช่วยเรื่องแก้/ลบผิด แต่ไม่ครอบคลุมการเสียสิทธิ์ทั้งบัญชี
7. **เป้าค่าใช้จ่าย 0–30 บาท/เดือน** เป็นการประมาณการ ไม่ใช่การรับประกันเพดานบิลของผู้ให้บริการ
